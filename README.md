Online Watch store

I developed an online watch store as a full-stack application, utilizing Java for backend logic, JavaScript and TypeScript for frontend interactivity, and Spring Boot as the primary framework. Angular was employed for building a dynamic user interface, ensuring a responsive and smooth user experience.

For data management, I integrated MySQL as the database, handling all storage and retrieval operations efficiently. The project showcases a combination of modern web technologies to create a functional and aesthetically pleasing e-commerce platform.
